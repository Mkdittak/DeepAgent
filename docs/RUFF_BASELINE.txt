195 findings across 26 files. 99 are auto-fixable with `ruff check --fix`.
None change program output today; a handful are latent reliability bugs.

Substantive (fix by hand, each worth an issue):

  1. Dangling background tasks — backend/main.py:852 and :880 (RUF006).
     asyncio.create_task() result is never stored. Python may garbage-
     collect an unreferenced task, which would silently kill the event
     persister mid-run and leave a finished run with no replayable log.
     Fix: keep the tasks in a module-level set, discard on completion.

  2. Blocking I/O inside async handlers — backend/main.py:431,450,452;
     agent/tools.py:258; temporal/activities.py:392 (ASYNC230/ASYNC240).
     open()/os.path.* on the event loop stall every other request or run
     while the disk call runs. Low impact on local SSD; real under load.
     Fix: asyncio.to_thread() or aiofiles, or move to the Postgres/object
     storage layer that replaces these paths anyway.

  3. Unused imports — agent/tools.py:140 (Inches, Pt);
     temporal/activities.py:11 (json); two test files (F401). Auto-fix.

  4. Files opened without close — tests/proof_auth_live.py:34,37,285;
     tests/test_concurrency.py:41,42 (SIM115). Leaks handles in long
     proof runs on Windows, where an open handle blocks deletion.

Cosmetic (safe to auto-fix in one commit, then `ruff format .`):

  - E701/E702/E401 (53): several statements or imports on one line,
    almost entirely in tests/.
  - I001 (35): unsorted import blocks.
  - RUF100 (24): stale `# noqa` comments that no longer suppress anything
    (E402 is now relaxed for tests/ in pyproject).
  - UP0xx (27): pre-3.10 syntax — Optional[X] -> X | None, open(..., "r"),
    datetime.timezone.utc -> datetime.UTC, printf-style formatting.

Intentional / leave as is:
